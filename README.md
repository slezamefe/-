# Crash Prototype

A single-page front-end prototype of a casino-style crash game experience. The UI is inspired by modern gaming dashboards, featuring a simulated multiplier chart, betting controls, and a compact history feed.

## Features
- Animated multiplier curve with gradient stroke and grid overlay.
- Configurable bet amount and optional auto cashout multiplier.
- Click-to-cash-out interaction that simulates winnings and updates an on-screen balance.
- Recent history list that highlights wins and losses.

## Getting started
No build tools are required. Open `index.html` in any modern browser to explore the interactive prototype.
